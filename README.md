# Event Management System

## Team 12

A Java-based Event Management System developed using Java programming language.

## Technologies Used
- Java
- Eclipse IDE
- Maven
- Jackson Library
- JSON

## Features
1. Add Events
2. View Events
3. Search Events
4. Update Events
5. Delete Events
6. Register Participants
7. View Participants
8. Cancel Registrations
9. Manage Event Capacity
10. Sort Events
11. Store and retrieve data using JSON

## Project Structure
- main – Main application
- model – Event, Participant, Organizer, Person, Registration and Venue classes
- repository – JSON data management
- service – Business logic
- util – Utility and demonstration classes

## How to Run
1. Import the project into Eclipse as an Existing Maven Project.
2. Update Maven dependencies.
3. Open Main.java.
4. Run as Java Application.
